# Freight Rate Prediction Assessment

Solution by Musaab. The model predicts the total posted price of a shipment in dollars. This package contains the submitted predictions, the required December chart, a PDF report, pinned dependencies, and a standalone script implementing the notebook workflow.

## Run from scratch

Use Python 3.11. The recorded runs used Python 3.11.9. The dependency versions are pinned from that environment.

Place the employer-supplied files in a `data` directory beside this README, using these names:

- `train_test.csv`
- `validation.csv`
- `validation_predictions_template.csv`
- `december_chart_inputs.csv`

From this directory in Windows PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_assessment.py
```

The script fits the chronological evaluation models, saves local metrics, fits the final pipeline on all 48,000 labeled records, produces both prediction CSVs, and runs the unchanged supplied checker. This reproduction performs model training.

On other systems, create a Python 3.11 environment, install `requirements.txt`, and run `python run_assessment.py`.

Optional arguments:

```text
python run_assessment.py --data-dir PATH_TO_INPUTS --output-dir PATH_TO_OUTPUTS
python run_assessment.py --predict-only --model-path PATH_TO_SAVED_MODEL
```

The second command uses an existing fitted pipeline and does not train a model. The saved pipeline consumes the output of `prepare_features()` in `run_assessment.py`; use that same preparation function for inference. A fitted model is generated by the full run and is excluded from the repository package.

## Verification

The saved final pipeline reproduced all 12,000 submitted predictions. The standalone script was checked in prediction-only mode with that pipeline: both output CSVs matched the saved notebook outputs within a tolerance of 1e-8, and the supplied checker passed. The full training path consolidates the notebook steps and was not rerun during packaging.

## Method

The first model uses inputs available in both the main datasets and the fixed December chart: pickup, delivery, distance, equipment, weight, and date. Date is represented by month and weekday. Nonpositive weights become missing. Numeric medians and missing indicators are fitted on training data only. City and equipment categories use one-hot encoding with unfamiliar categories ignored. The prepared array has 136 columns in the reported runs.

The regressor is scikit-learn's HistGradientBoostingRegressor with absolute-error loss, learning rate 0.05, 300 iterations, at most 31 leaves per tree, minimum 30 samples per leaf, L2 regularization 1.0, early stopping disabled, and random seed 42. The baseline uses the training median of price per mile times distance.

## Files

- `01_exploration.ipynb`: the step-by-step analysis and training workflow. The package includes a reviewed copy with unused intermediate arrays and an empty cell removed; its outputs are cleared because it was edited.
- `run_assessment.py`: feature preparation, evaluation, final training, and exports.
- `score.py`: unchanged employer-supplied output checker and chart generator.
- `requirements.txt`: pinned environment dependencies.
- `validation_predictions.csv`: 12,000 load IDs and predicted prices in template order.
- `december_predictions.csv`: the 31 fixed December inputs with predicted prices.
- `scorer_results/candidate_december.png`: required generated chart.
- `report.pdf`: approach, splits, results, chart, and limitations.
- `reports/validation_results.csv` and `reports/local_test_results.csv`: local metrics.

Input datasets, local environments, fitted models, and row-level error logs are excluded from version control. The reviewer supplies the original inputs to reproduce the results. The PDF and run script describe model limitations; the chart is a prediction scenario, not observed market data.

## Checker only

```text
python score.py --predictions validation_predictions.csv --december-predictions december_predictions.csv
```

Checker success validates output structure and positive values and generates the chart. It does not measure hidden-label prediction accuracy.
